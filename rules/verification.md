# Verification Before Action

- NEVER guess at file paths, UI locations, or config locations. Use `find`, `fd`, `grep`, or check documentation/online sources before suggesting paths.
- When user states a version or fact (e.g., 'I have v0.16'), trust it and search for that specific version's docs; do not default to older/different versions.
- Before diagnosing, verify the actual state with commands rather than assumptions.
